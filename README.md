Спринт7 Автотесты для API учебного сервиса заказа самокатов: https://qa-scooter.praktikum-services.ru/ 

## **Функционал тестирования**
1. **Создание курьера**
   - Проверка успешного создания курьера.
   - Обработка дублирования логина.
   - Проверка обязательных полей (login, password, firstName).
   - Корректные коды ответов и тело ответа ({"ok": true}).

2. **Логин курьера**
   - Авторизация с валидными данными.
   - Обработка неверных учетных данных.
   - Проверка обязательных полей (login, password).
   - Проверка на возврат id в ответе.

3. **Создание заказа**
   - Параметризованные тесты для цветов (BLACK, GREY, оба, отсутствие цвета).
   - Проверка наличия track в ответе.

4. **Список заказов**
   - Проверка структуры ответа, а orders — список.

# Установите зависимости
pip3 install -r requirements.txt

# Запустите тесты с Allure
pytest --alluredir=./target/allure-results

# Сгенерируйте отчёт
allure serve ./target/allure-results
